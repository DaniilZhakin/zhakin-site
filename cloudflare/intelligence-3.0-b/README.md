# Intelligence 3.0-B — безопасный сбор обезличенных событий

Статус: IMPLEMENTATION SKELETON / HOLD

Этот каталог содержит подготовленный кодовый каркас для будущего Cloudflare Worker. Он **не подключён к сайту и не собирает данные в production**.

## Простыми словами

Сайт останется на GitHub Pages. Маленькая серверная программа (Worker) будет принимать только заранее разрешённые обезличенные события и сохранять их в базе D1.

## Что подготовлено

- `src/worker.js` — минимальный обработчик `POST /api/events`;
- `schema.sql` — таблица для событий;
- строгий allow-list полей и типов событий;
- отказ от неизвестных полей;
- запрет потенциально персональных значений в контролируемых полях;
- CORS для canonical/public origin;
- ограничение размера запроса;
- серверное время получения события;
- заготовка rate-limit hook без внешнего сервиса.

## Важно

До подключения реального Cloudflare runtime не создаём production endpoint, не добавляем секреты в GitHub и не включаем отправку событий с сайта.

PASS будет только после фактического развёртывания и отрицательных/положительных тестов в production.
