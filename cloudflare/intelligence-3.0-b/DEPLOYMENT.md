# Intelligence 3.0-B — запуск

Статус: READY FOR RUNTIME / HOLD

Этот документ описывает последний шаг перед реальным запуском. Сам по себе он ничего не включает и не создаёт production-сбор данных.

## Что должно произойти

1. Создаётся Cloudflare Worker.
2. К нему подключается база D1 с таблицей из `schema.sql`.
3. Публикуется адрес `POST /api/events`.
4. Разрешается отправка только с `https://жакин.рф` и его canonical HTTPS-origin.
5. Включается реальное ограничение частоты запросов.
6. Выполняется тестовый набор из `TEST-PLAN.md`.
7. Только после успешных тестов сайт получает право отправлять события.

## Запреты

- Не добавлять API-токены, пароли, ключи или идентификаторы Cloudflare в Git.
- Не хранить IP-адреса, fingerprint, email, телефон или рекламные идентификаторы.
- Не включать production endpoint до завершения тестов.

## Условие PASS

PASS возможен только после фактического ответа production endpoint, успешной записи разрешённого события в D1 и прохождения всех отрицательных тестов.

До появления рабочего Cloudflare runtime статус остаётся HOLD.
