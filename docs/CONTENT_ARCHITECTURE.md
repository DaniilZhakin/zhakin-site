# Архитектура контента — жакин.рф

## Назначение

Публикации должны работать не как архив отдельных материалов, а как единый аналитический контур: тема → материал → связанный материал → следующий уровень анализа.

## Текущий контур

- `/publications.html` — публичный каталог публикаций.
- 13 материалов описаны в `ItemList` Schema.org.
- Каждая публикация имеет отдельную URL-страницу и собственную SEO-разметку.
- Публикации охватывают финансы, инвестиции, AI, государственное управление, право, инфраструктуру и стратегическое развитие.

## Принцип группировки

Основные аналитические вертикали:

1. **Финансы и инвестиции** — деньги, капитал, финансовая система, рынок.
2. **AI и государство** — искусственный интеллект, управление, интеллектуальная инфраструктура.
3. **Право и институты** — государство, право, процедуры, институциональная архитектура.
4. **Инфраструктура и экономика** — энергия, продовольствие, физическая и цифровая инфраструктура.
5. **Стратегическое развитие** — долгосрочные сценарии, экономические переходы и новая архитектура.

## Правила для новых материалов

- Каждая новая публикация получает уникальный slug.
- На странице каталога указывается вертикаль и тип материала.
- Новая публикация добавляется в `ItemList` только один раз.
- Материал должен иметь минимум одну смысловую связь с другим материалом, если такая связь существует.
- Не смешивать авторскую аналитику с новостной лентой.
- Внешняя публикация (например, VC.ru) может быть источником/версией материала, но официальный сайт остаётся самостоятельным контентным контуром.

## Следующий функциональный слой

Следующим этапом допускается добавить клиентскую фильтрацию каталога по аналитическим вертикалям. Фильтрация должна быть progressive enhancement: без JavaScript все публикации остаются доступны и индексируемы.

## Ограничения

- Не добавлять CMS или серверную базу данных без отдельного архитектурного решения.
- Не вводить автоматическую публикацию без проверки автора.
- Не скрывать материалы от поисковых систем только ради UI-фильтров.
- Не менять существующие SEO URL без необходимости.
