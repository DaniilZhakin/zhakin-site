# Release 1.8.3.1 — Foundation Integration & Digital Ecosystem

## Статус

**In progress**

Release 1.8.2 «Restore USERDIE Foundation Module» принят как завершённый в статусе **Accepted / Deferred Integration**. Отдельный расширенный модуль фонда не блокирует развитие официального сайта.

## Цель этапа

Развивать официальный сайт Даниила Жакина от текущего состояния ветки `main`, сохраняя действующую SEO-архитектуру и подготавливая безопасную интеграцию Благотворительного фонда «УСЕРДИЕ» и направления USERDIE Digital.

## Зафиксированное текущее состояние

- официальный домен используется в `canonical` и Open Graph;
- на главной странице присутствует базовая Schema.org-разметка типа `Person`;
- Благотворительный фонд «УСЕРДИЕ» уже упомянут в разделе стратегических проектов;
- отдельный большой раздел фонда не является обязательным условием для продолжения разработки;
- текущая навигация и визуальная структура сохраняются до отдельного утверждённого изменения.

## Рабочий контур

1. Проверка валидности HTML и внутренних якорных ссылок.
2. Проверка согласованности `title`, `description`, `canonical`, Open Graph и Twitter Card.
3. Подготовка расширенной JSON-LD-модели без удаления существующей сущности `Person`.
4. Формирование связей между официальным сайтом, персональным профилем, брендом ZHAKIN TEAM и фондом «УСЕРДИЕ».
5. Интеграция USERDIE Digital только после подтверждения публичных URL и фактического статуса проекта.
6. Все изменения выполняются в отдельной ветке и проходят через pull request.

## Ограничения

- не возвращаться к завершённым релизам;
- не удалять действующие SEO-метаданные;
- не добавлять неподтверждённые должности, юридические связи или контактные данные;
- не менять структуру главной страницы без отдельной необходимости;
- не считать изменение выполненным без коммита и проверки diff.

## Критерии приёмки

- HTML сохраняет корректную структуру;
- все пункты навигации ведут к существующим идентификаторам;
- JSON-LD является синтаксически валидным;
- существующие метаданные не утрачены;
- фонд представлен без ложного указания должности Даниила Жакина;
- изменения документированы в pull request;
- после слияния ветка `main` остаётся пригодной для GitHub Pages.
