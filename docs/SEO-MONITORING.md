# SEO 2.5 — Monitoring & Intelligence

## Назначение

Слой 2.5 переводит SEO-инфраструктуру сайта из режима разовой проверки в режим постоянного наблюдения за production-состоянием.

## Что контролируется

- доступность `robots.txt`;
- соответствие robots policy production-домену;
- доступность и целостность `sitemap.xml`;
- отсутствие дублей и внешних URL в sitemap;
- покрытие обязательных страниц sitemap;
- HTTP-доступность ключевых production-страниц;
- наличие корректного canonical;
- отсутствие `noindex` / `X-Robots-Tag` сигналов в HTML;
- наличие JSON-LD как базового структурированного слоя;
- время ответа каждой проверяемой страницы;
- машинный JSON-отчёт и человекочитаемый Markdown-отчёт как GitHub Actions artifact.

## Режим работы

Workflow: `.github/workflows/seo-monitoring.yml`

- запускается при push в `main`;
- запускается ежедневно по расписанию;
- доступен ручной запуск через GitHub Actions (`workflow_dispatch`);
- при критическом отклонении job завершается с ошибкой;
- отчёт сохраняется независимо от результата проверки.

## Архитектура контроля

`Production → HTTP checks → SEO signal checks → structured report → GitHub Actions status`

Слой 2.5 не изменяет сайт автоматически и не выполняет destructive actions. Его задача — рано обнаруживать деградацию SEO-инфраструктуры и давать воспроизводимый диагностический след.

## Следующий уровень

После стабилизации 2.5 можно перейти к 2.6: trend intelligence — накопление результатов проверок, сравнение response time и SEO-сигналов во времени, а также автоматическая фиксация аномалий.
