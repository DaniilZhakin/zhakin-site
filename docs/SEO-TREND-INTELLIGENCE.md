# SEO 2.6 — Trend Intelligence

## Назначение

Слой 2.6 переводит production SEO monitoring из снимка состояния в накопительную систему наблюдения: результаты проверок сохраняются во времени, сравниваются с предыдущим снимком и проверяются на регрессии.

## Что добавлено

- ежедневный production snapshot;
- история до 30 последних снимков в `monitoring-history/seo-history.json`;
- контроль robots policy и sitemap coverage;
- доступность и SEO-сигналы всех обязательных страниц;
- фактический HTTP `X-Robots-Tag` отдельно от HTML meta robots;
- среднее и максимальное время ответа;
- сравнение текущего состояния с предыдущим снимком;
- автоматическое выявление регрессий и резкого роста среднего response time;
- JSON и Markdown trend report как GitHub Actions artifact.

## Архитектура

`Production → Snapshot → History → Comparison → Anomaly detection → Report`

История ограничена 30 снимками, чтобы контроль оставался компактным и воспроизводимым.

## Безопасность изменений

Слой не изменяет production-сайт. Единственное автоматическое изменение репозитория — обновление файла накопленной истории мониторинга. При отсутствии изменений новый commit не создаётся.

## Следующий уровень

После накопления достаточного ряда наблюдений можно добавить более глубокую baseline-модель: rolling median/percentiles, устойчивые пороги аномалий и автоматическое создание GitHub Issue только при подтверждённой деградации.
